# MagicItem

魔法物品插件

## 配置

### config.yml

```yml
# 全局冷却（药水效果的），开启后所有物品均公用一个冷却计算
GlobalItemCooldown: false
# 展示手中物品的冷却，单位秒
ItemDisplayCooldown: 15
# 更新到命名空间 ID，保持 false 即可
updateItemIdToSpacename: false
# 品质，不同品质属性会被乘以不同的系数
quality:
  # 品质显示的文本
  list: 
  - 劣质
  - 普通
  - 优质
  - 完美
  - 传奇
  # 概率，其合应为 1
  p: 
  - 0.3
  - 0.4
  - 0.15
  - 0.04
  - 0.01
  # 系数
  m: 
  - 0.8
  - 1
  - 1.2
  - 1.5
  - 2
# 禁用 MagicItem 的世界
RestrictedWorlds: 
  - zc
```

### items/example.yml
```yml
# 物品字符串ID
物品ID: minecraft:diamond
# 物品特殊值也叫 aux
物品Meta: 0
# 物品显示名
名字: 演示魔法物品
# 玩家使用时获得的药水
获得药水:
  - 1:1:10
  - 2:1:2
# 玩家使用时获得的群体药水
群体药水:
  - 1:1:10
  - 2:1:2
# 药水作用范围
药水范围: 5
# 暂且无用
群体药水作用对象: 0
# 玩家使用时是否产生雷击
使用雷击: false
# 管理员权限执行命令
# 可使用变量：
# {player}   玩家名
OP指令:
  - say {player}
# 玩家自身执行命令
以玩家身份执行:
  - me test
# 物品附魔，格式：
# 附魔ID:附魔等级
附魔:
  - 0:1
# 物品 Lore
显示:
  - 第一行
  - 第二行
# 使用是否会消耗物品
使用消耗: false
# 回收价格，使用 EconomyAPI 经济
# 为 0 时不回收
回收价格: 0
# 暂且无用
职业限制: 无
# 物品使用冷却，单位秒
冷却时间: 0
# 玩家获得物品时（仅通过命令 /mi give 获取时），发送给玩家的消息
获得提示: 恭喜获得魔法物品
# 玩家获得物品时（仅通过命令 /mi give 获取时），发送给全服玩家的消息
# 可使用变量：
# {player}   玩家名
全服提示: 恭喜 {player} 获得魔法物品
```
## 命令

### `/mi reload`

重载配置文件
这个命令用于重新加载MagicItem的配置文件，确保所有的设置都是最新的。当你对配置文件做出更改后，使用此命令可以使更改立即生效。

### `/mi add <String: itemName> <String: itemId>`

添加（创建）新的魔法物品
使用此命令可以添加一个新的魔法物品到你的库存中。你需要指定物品的名称（itemName）和物品ID（itemId），它们是识别物品的关键信息。

### `/mi give <Player: player> <String: itemName> [Int: count] [Int: quality]`

给予玩家指定的魔法物品
通过这个命令，你可以将特定的魔法物品给予指定的玩家。除了需要指定玩家和物品名称外，你还可以指定给予的数量（count）和物品的品质（quality）。

### `/mi show`

展示手中物品
执行此命令后，将展示你当前手中持有的魔法物品的详细信息。

### `/mi sell`

出售背包的魔法物品
如果你想要出售背包中的魔法物品，可以使用这个命令。它会将你背包中的魔法物品转换为游戏货币。
